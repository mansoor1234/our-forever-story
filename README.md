# Our Forever Story ❤️

A romantic, mobile-friendly anniversary surprise for My Love.

## Hosting

This is a static website. GitHub Pages should publish from **main** → **/(root)**.

Visit: https://mansoor1234.github.io/our-forever-story/

## Personalize

Edit `index.html` → `settings` to specify your wedding date (`YYYY-MM-DD`) and nickname. Upload your photos as `photos/memory-1.jpg` through `photos/memory-4.jpg`.

The music toggle is off by default and can be enabled by visitors.
